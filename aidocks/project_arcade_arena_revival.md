**Path note (post-restructure):** this log predates the repo reorg — every `includes/...` path below now lives under `src/includes/...`, and `data/...`/`docks/...`/`sounds/...` now live under `sf/...` (code strings stay cwd-relative). The arena subsystem is `src/includes/main/globals/arena.nvgt`. See [[project_path_conventions]].

SimpleFighter's next major version (14.0, not started as of 2026-06-05) revives the arcade survival shooter that was the game's original flagship mode (present 1.0–6.9) and was fully removed in 7.0 ("This game will now be a pure map builder moving forward"). Goal: a "launch and play" front door for new players — pick a target, fight escalating waves on a procedurally-set-up arena — rebuilt on the modern 13.9 engine. It is a remodernization, NOT a faithful code port and NOT a feature expansion.

**Why:** A player (Sky gamer) reported the game is no longer beginner-friendly — it forces map-building / content-authoring before you can even play. The combat engine, stock content (271 weapons / 42 shields / 187 NPCs), and the `/spawn` → `dispatch_entity_line` runtime primitive all still exist; only the front-door arcade mode is missing. The `/spawn` path (spawns live entities with no map file) is conceptually the old arcade. Reference source WAS the untouched old code at `user/SimpleFighter-6.90/` (`game()`/`gamemenu()`/`normalmenu()`/`custommenu()` in `includes/game.nvgt` + `menu.nvgt`) — the dev DELETED that folder on 2026-06-05 after the revival shipped, so it no longer exists on disk.

**How to apply (settled design decisions):**
- New subsystem `includes/main/globals/arena.nvgt` (runtime, not a map entity; class is fine, only one arena at a time). Wire `arenaloop()` into `game.nvgt`'s `if(freezgame==false)` block; add teardown to the `destroy_all_*` run in `map.nvgt`.
- Spawning = wrap ONE full-map `npc_zone` — it already does random-subtype resolution, the spawn timer, path any/global/map, and 2d/topdown/3d coords (y/y2 = depth, z = height). The arena only adds the population cap + the level-ramp.
- Targets: animals, humans, robots, zombies ONLY. NOT bosses, specials, helpers (allies), or projectiles ("those aren't NPCs").
- Difficulty = faithful rising swarm: bump BOTH `scale_level` and the cap on level-up (6.9 did both). `scale_level` overrides info-file stats. TUNING: cap = base_cap (default 1, so start with 1 alive) + level - 1, hard-clamped to `arena_max_cap=50` (never >50 alive); via `arena_cap()` in arena.nvgt. Cap counts LIVE npcs via `npc_live_count()` in npc.nvgt (dead npcs are sentinel-null so `npcs.length()` over-counts — that was the "stops spawning after N kills" bug; fixed).
- Cut from the 6.9 original: heart monitor; the `building` flag (pure arcade now); the 5 parallel spawn timers/caps/arrays (collapse to one); the `spawnable` flag (already gone in 13.9 — `freezgame` gates the whole entity loop, so pause halts spawning for free).
- Mode/coords: read global `mapmode` + bounds (`minx/maxx/miny/maxy/minz/maxz`). `spawn_arena` carries the coord fields explicitly (double), mirroring `npc_zone`.
- Setup = ONE form (modeled on new-map form): map mode + platform + music + source lists, each defaulting to "none"; NO vol/pitch sliders; previewers KEPT; EXCLUDE the air tile from the platform list. platform "none" = no platform spawned (silent arena).
- Size: fixed start 50x50 (2d/topdown), 50x50x50 (3d); min always 0. In-game F-keys grow/shrink MAX only: F1/F2 = -/+ maxx, F3/F4 = -/+ maxy, F5/F6 = -/+ maxz (3d only), step 5 tiles, live-resizing the floor + the npc_zone. A max edge can be shrunk no lower than 25 (`arena_min_max` in arena.nvgt). Readout: comma/period/slash speak max x/y/z.
- Disabled in arena (anti-cheat / unneeded): command console, grappling hook, sonar, AND falling (flat arena; reuse an existing fall flag if one exists, else gate `fallcheck()`). ALSO the jump-height keys (F1-F3): `handle_height_keys()` is gated `if(!arena_active)` in `game_input.nvgt` — dev-confirmed this was intentional anti-cheat (a high jump height lets you float over the swarm and dodge enemies), and it freed F1-F3 to become the arena resize controls. So jump height can only be changed on maps, never in the arena — which is also why jump height is not in the arena save (nothing to persist there); contrast speed, whose shift+A/D/F keys DO work in the arena and IS saved. Camera + spire KEPT as-is. Also in arena mode HIDE BOTH the "all" tab AND the "specials" tab in the weapons menu (specials holds glider + cloner = cheat vectors; the all tab would otherwise aggregate them). Remaining tabs: archery / artillery / explosive / melee.
- Death: existing try-again prompt; "yes" respawns at 0,0 (2d/topdown) or 0,0,0 (3d). No save system for now.
- Spawn-safe corner: on arena start, spawn ONE safe zone at the origin via `spawn_safezone(x1,x2,y1,y2,type,minz,maxz)` (fields already double) with `type = get_map_sound_folders("builder/zones/safe zones/*")[0]`. Dims: 2d (0-10, 0-5); topdown (0-10, 0-10); 3d (0-10, 0-10, z 0-5). Height axis = 0-5, horizontal/depth = 0-10. Enemies physically can't enter a safe zone — `npc.nvgt` movement check uses `is_in_safe()` like a wall. To stop enemies SPAWNING on it, the arena's npc_zone starts at x=11 (past the corner) with `auto_spawn=true`.
- DONE (compiles): added runtime-only `bool auto_spawn` to npc_zone.nvgt (field + `au=false` ctor param + `auto_spawn=false` on spawn_npc_zone + `npczoneloop` gate changed to `(auto_spawn or trigger)`). Default false = unchanged (player must be in zone); true = spawn on timer regardless of player position. NOT serialized — same minimal pattern as `cap`.
