commands.

The command console accepts the following commands, which can also be fired from macros and apply when building command blockers.

The command console cannot be opened during an arcade arena run, so none of these commands can be typed while you're in the arena.

Any numeric argument to any of these commands can be written as random(low,high) instead of a literal number, and a fresh value between low and high (inclusive) gets rolled each time the command runs. So /spawn bomb random(3,7) 0 1000 2000 bomb5 drops a bomb at a random x between 3 and 7 every time it fires, and /go random(0,100) 0 teleports you to a random horizontal tile within the named range. The token works in every numeric field of every command because the engine's string-to-number routine recognizes it, which also means it works for any numeric field in any hand-authored entity line in main.sif (coordinates, ranges, counts, speeds, healths). The roll is independent on each call, so a switch or macro that fires the same random-bearing command repeatedly gets a new value every time.

Character and position tokens.

Alongside random, a set of tokens expands to your character's live values the moment a command runs, so a command can report or reuse a number without you having to know it in advance. Write any of them inside a command and it is replaced with the current value: %health%, %maxhealth%, and %healthpc% (your health, its maximum, and your health as a percentage of that maximum); %stam%, %maxstam%, and %stampc% (the same three for stamina); %level%, %xp%, %points%, %lives%, and %kills%; and %x%, %y%, and %z% for your position, where z is meaningful only on 3d maps. The two percentages are given to two decimals, the same as the statistics screen. So /speak %health% of %maxhealth%, %healthpc% percent speaks something like 140 of 200, 70 percent.

Because each token is resolved when its own command actually runs, a token placed after a command that changed the value reads the new value: setx 50; speak you moved to x %x% speaks 50, and sethealth 50 true; speak your health is now %healthpc% percent reports the health you just set. These tokens work in every command, everywhere a command can appear: the console, a macro, a switch or sensor, an input, or a map timer.

Command stacking and delays.

Any place that accepts a single slash command also accepts a stack of them, separated by semicolons, so /give bullets 50; /play alarm; /cm reload 10 10 runs three commands top to bottom from one input. Stacking works identically whether you type the stack into the command console, bind it to a macro, attach it to a switch's on or off field, or list it inside a command blocker's allow or block list. Each step accepts an optional millisecond delay written as a number before the command, so /speak alert; 2000 /speak intruder detected; 3000 /play alarm speaks alert immediately, waits 2 seconds and speaks intruder detected, then waits another 3 seconds and plays the alarm. A delay with no command (a bare number followed by a semicolon) is a no-op pause, and a command with no delay runs as soon as the prior step's delay has elapsed.

Stacked commands and their delays run asynchronously — the call that fires the stack returns control to you instantly, and the delayed steps fire in the background while you keep moving, fighting, and hearing the rest of the map. A multi-second narrative chain or a long ambush sequence will not freeze input, sound, or screen-reader output; the engine queues each step against its own timer and fires it when its scheduled time arrives, which also means an auto-activated switch with chained delays on its on command doesn't stall the map load. The slash at the start of each step is optional — the engine prepends one if you forget — and a malformed step fails silently the same way it would if you typed it into the console alone. The semicolon character is reserved as the stack separator, so commands whose arguments would need a literal semicolon can't be stacked unmodified.

Commands on compiled maps.

Some commands behave differently once a map is compiled and shipped, because a compiled map is read-only. There are three cases, and each command below notes which one applies. Most commands work normally on a compiled map. A group of editing commands — build, newmap, delmap, rawmap, rawdata, undomap, redomap, maperrors, and menu — never work on a compiled map, because there is no editable map file for them to act on. A middle group — spawn, go, gozone, suicide, and the position commands from addx through setz — work on a compiled map only when a switch, sensor, input, or map timer fires them, not when you type them into the console or fire them from a macro, so a map author can wire them into the map's own machinery while a player can't use them to skip past its design. Changemap is the exception in that group: it works on a compiled map even when typed, so you can travel between compiled maps.

/addhealth amount, or /aht amount: Adds the amount to your character's health, up to full. Append true to make the amount a percentage of the maximum, or false for an exact value, the default. Runs silently.
/addlevel amount, or /alv amount: Adds the amount to your character's level, recomputing the experience needed for the next level; it does not award the usual level-up points. Runs silently.
/addlife amount, or /alf amount: Adds the amount to your character's remaining lives. Runs silently.
/addpoints amount, or /apn amount: Adds the amount to your character's points, the currency spent in the shop. Runs silently.
/addstam amount, or /ast amount: Adds the amount to your character's stamina, up to full. Append true to make the amount a percentage of the maximum, or false for an exact value, the default. Runs silently.
/addtime time, or /att time: Adds the time to the current map timer's remaining clock. The time is a number of seconds or clock form like 1:30. Runs silently, or says there's no timer if the map has none.
/addx amount, or /ax amount: Adds the amount to your character's x position, clamped to the map's minimum and maximum. Runs silently; on a compiled map it works only when fired by a switch, sensor, input, or map timer, not when typed.
/addxp amount, or /axp amount: Adds the amount to your character's experience; earning enough levels you up normally, awarding the usual points and level-up sound.
/addy amount, or /ay amount: Adds the amount to your character's y position, clamped to the map's minimum and maximum. Runs silently; on a compiled map it works only when fired by a switch, sensor, input, or map timer, not when typed.
/addz amount, or /az amount: Adds the amount to your character's z position, its height on a 3d map, clamped to the map's minimum and maximum; it has no effect on 2d or topdown maps, which have no z axis. Runs silently; on a compiled map it works only when fired by a switch, sensor, input, or map timer, not when typed.
/build object, or /bl object: Build an object containing a specified prompt. Typing the object name alone opens the builder form for that object as before. Appending the object's fields after the name skips the form and places the object directly with those fields. It works only on decompiled maps.

For example: /build platform 0 10 0 10 0 100 marble 0 100 false false places a platform without opening any dialog. The inline form is the authoring verb: it writes the line to the map's main.sif and reloads, so the placement is permanent and survives across map loads. Use /build from a macro or the command console when you want to add content to the map that should stay there; for switch bindings that should only spawn something temporarily, use /spawn instead (described below). The order and type of the fields after the object name match the entity's on-disk line format, so a hand-authored main.sif line and a /build inline argument string are interchangeable.
The object name accepts either the friendly form (the same name the builder menu uses, like moving_platform or security_camera) or the abbreviated on-disk form (like mplatform or camera) — both resolve to the right entity, so you can use whichever you remember. The item-mode form keys (item_door, item_passage) resolve to their non-item siblings on disk, and item-mode activates through the lockmode field in the inline args rather than the entity name itself. A malformed inline build silently fails to load that one line on reload while leaving the rest of the map intact.

/changemap mapname x y, or /cm mapname x y: Changes your map to a specified coordinate. On 3d maps the form is /changemap mapname x y z, or /cm mapname x y z, where z is the height to drop you in at. This works on both decompiled and compiled maps; on a compiled map it loads the destination's compiled copy when one exists, otherwise its decompiled version.
/charset category, or /chr category: Changes your current character theme to a different one. Typing /chr with no arguments will display a menu of all available character themes.
/delmap, or /dm: Deletes the map you're currently playing after a yes/no confirmation dialog. Append false to skip the prompt and delete immediately, e.g. /delmap false from a macro that doesn't want the safety question; true is accepted as the explicit form of the default. The deletion is permanent — false should be used with care. It works only on decompiled maps.
/draw weapontype weapontype2, or /dr weapontype weapontype2: Equips any weapon with a given type.
/gamestart, or /gs: Unfreezes the game.
/gamestop, or /gp: Freezes the game.
/getall, or /gl: Collects all of the items on the map and gives them to your character.
/give item amount, or /gv item amount: Gives your character an item with a specified amount.
/giveall amount, or /ga amount: Gives your character the specified amount of every item type found across the health, other, and stamina item categories. A negative amount recycles those quantities back out of your inventory instead of adding them, and an amount of zero is a no-op.
/go x y, or /go entity id x y: Moves your character or an npc to a specified coordinate on the map. On 3d maps the form is /go x y z, or /go entity id x y z, where z is the height. This command supports moving the folowing entities. Animals, bosses, helpers, humans, robots, specials, and zombies. On a compiled map this runs only when fired by a switch, sensor, input, or map timer, not when typed.
/gozone, or /gz: Opens a menu listing the text zones available on the current map so you can pick one to teleport to. Append a zone name to teleport directly without opening the menu, e.g. /gozone main entrance — multi-word names are supported, and the lookup is case-insensitive against the zone's text field. Speaks an error if the named zone doesn't exist on the current map. On a compiled map this runs only when fired by a switch, sensor, input, or map timer, not when typed.
/healbones, or /hb: Heals all of your broken bones to being fully functional again.
/healhealth, or /ht: Restores your character's health to full. This is the health counterpart to /healbones, and it leaves your stamina untouched. Speaks a notice if your health is already full.
/healstam, or /hs: Restores your character's stamina to full. This is the stamina counterpart to /healbones and /healhealth, and it leaves your health untouched. Speaks a notice if your stamina is already full.
/help topic, or /hp topic: Brings up a menu containing useful information for a particular topic of interest. Typing this command with no arguments will bring up a menu containing all help topics of interest.
/invclear, or /ic: Clears your entire inventory.
/kill entity id x y, or /kn entity id x y: Kills an npc at a specified coordinate on the map. This command supports killing the folowing entities. Animals, bosses, helpers, humans, robots, specials, and zombies.
/killall, or /kl: Kills all of the npcs on the map. This command supports killing the folowing entities. Animals, bosses, helpers, humans, robots, specials, and zombies.
/kills, or /kls: Speaks how many entities your character has killed in total, the same figure shown on the statistics screen.
/level, or /lv: Speaks your character's current level and experience, and how much more experience the next level requires, the same as the statistics screen.
/loc: Speaks your character's current position, then the map's minimum and maximum along each axis. On 2d and topdown maps this reads out your x and y; on 3d maps your z, the height, is included as well. Your location comes first, followed by each axis in turn with its minimum and maximum spoken together, so you can tell at a glance where you are and the full range of the map in every direction.
/macset category category2, or /mc category category2: Changes your current macro pack to a different one. Typing /mc with no arguments will display a menu of all available macro packs.
/maperrors, or /ms: Checks the map you're currently on for invalid lines and lists any it finds in the map errors box, or tells you there are none. It works on any decompiled map you're standing on, no matter how you reached it, so it's the way to check a map you arrived at through a travelpoint, or to bring the error box back if you closed it before you were done. See the maps topic for what makes a line invalid and when the box appears on its own.
/mapinfo, or /mi: Opens a read-only dialog with the loaded map's name, owners, description, creation date, modification date (each with how long ago that was), and total size on disk. Works on both decompiled and compiled maps.
/maps, or /mp: Opens a menu listing the decompiled maps you can load. Append a map name to load it directly without opening the menu, e.g. /maps 3d_test, suitable for binding to a macro or switch that jumps to a known map. Speaks an error if the named map doesn't exist as a decompiled folder.
/maptime, or /mt: Speaks how much time is left on the current map's timer, such as you have one minute and thirty seconds to complete this map, or tells you there's no timer if the map has none. See the map timer topic for how a timer is set up.
/menu, or /mu: Brings up a menu with several options related to the map you're currently on. You can also build this menu as an alternative to typing the command. It works only on decompiled maps.
/miscsounds, or /mcs: Opens a menu listing every misc sound available to the play command, sorted by name. Move through the list to hear each name spoken, press space to play the highlighted sound, and escape to close. It draws from the same place the play command does, so any sound here can be played by name with play.
/newmap, or /nm: Creates a new map. It works only on decompiled maps.
/play sound, or /pl sound: Plays a sound from the misc sounds folder with a given file name. The misc sounds folder is checked in both its decompiled and compiled forms (sounds/decompiled/main/misc and sounds/compiled/main.spack), so a clip served out of either location is playable by name. See the packs help topic for the full explanation of how the two forms interact.
/points, or /pt: Speaks how many points your character has available to spend in the shop, the same figure shown on the statistics screen.
/preffs, or /pf: Brings up the global settings menu. You can also find this in the main menu of the game.
/rawmap, or /rp: Copies the entire data of your map to the clipboard. It works only on decompiled maps.
/rawdata, or /rd: Pastes the entire data of your map from the clipboard after a yes/no confirmation dialog. Append false to skip the prompt and overwrite immediately, e.g. /rawdata false from a macro that doesn't want the safety question; true is accepted as the explicit form of the default. The overwrite replaces the map's entire main.sif and is permanent — false should be used with care. It works only on decompiled maps.
/redomap, or /ro: Reapplies the most recent change you took back with /undomap, stepping forward again through edits you've undone. As with undo, you can redo repeatedly until you've caught back up to where you were. Making a fresh edit after undoing clears anything that was waiting to be redone, since the map has taken a new direction from that point. Speaks a notice if there's nothing to redo. It works only on decompiled maps.
/relchar, or /rc: Reloads your current character. This will also clear your inventory, and reset all of your broken bones to being fully functional again.
/relmap, or /rm: Reloads the current map after a yes/no confirmation dialog. Append false to skip the prompt and reload immediately, e.g. /relmap false from a macro that doesn't want the safety question; true is accepted as the explicit form of the default.
/relshields, or /rs: Reloads all shields. This will also unequip the last shield that has been equipped to your character.
/relscripts, or /rt: Reloads all macros.
/relweps, or /rw: Reloads all weapons.
/scriptmode, or /sm: toggles using macros on or off.
/sethealth amount, or /stht amount: Sets your character's health to the amount, capped at full; setting it to zero costs a life, or ends the game on your last life. Append true to make the amount a percentage of the maximum, or false for an exact value, the default. Runs silently.
/setlevel amount, or /stlv amount: Sets your character's level to the amount, never below level one, recomputing the experience needed for the next level and trimming experience so the level sticks; it does not award level-up points. Runs silently.
/setlife amount, or /stlf amount: Sets your character's remaining lives to the amount. Runs silently unless set to zero, which ends the game.
/setpoints amount, or /stpn amount: Sets your character's points to the amount, the currency spent in the shop. Runs silently.
/setstam amount, or /stst amount: Sets your character's stamina to the amount, capped at full. Append true to make the amount a percentage of the maximum, or false for an exact value, the default. Runs silently.
/settime time, or /stt time: Sets the current map timer's remaining clock to an exact value, keeping its commands. The time is a number of seconds or clock form like 1:30; setting it to zero ends the timer and runs its time command. Runs silently, or says there's no timer if the map has none.
/setx amount, or /stx amount: Sets your character's x position to the amount, clamped to the map's minimum and maximum, teleporting you along that axis. Runs silently; on a compiled map it works only when fired by a switch, sensor, input, or map timer, not when typed.
/setxp amount, or /stxp amount: Sets your character's experience to the amount; setting it high enough levels you up normally, awarding the usual points and level-up sound.
/sety amount, or /sty amount: Sets your character's y position to the amount, clamped to the map's minimum and maximum, teleporting you along that axis. Runs silently; on a compiled map it works only when fired by a switch, sensor, input, or map timer, not when typed.
/setz amount, or /stz amount: Sets your character's z position, its height on a 3d map, to the amount, clamped to the map's minimum and maximum; it has no effect on 2d or topdown maps, which have no z axis. Runs silently; on a compiled map it works only when fired by a switch, sensor, input, or map timer, not when typed.
/silence, or /si: Immediately stops every sound started by the /play command. These miscellaneous sounds can overlap and stack on top of one another, so this is a quick way to clear them all at once. Sounds that belong to the map and the game itself, such as music, entities, and your character, are left playing.
/speak text, or /sk text: Speaks any text given by the user.
/spawn object fields, or /sp object fields: The ephemeral cousin of /build. Takes the same arguments — the object name followed by the entity's on-disk fields — and places the entity in the map immediately.

Unlike /build, the spawn is never written to main.sif and the map is never reloaded; the entity exists only in memory and will be gone the next time the map loads. The object name alone (with no fields) speaks an error rather than opening any dialog, since /spawn has no interactive form.
This is the verb to use from a switch's on or off command when you want the switch to summon something temporarily without permanently editing the map. On a compiled, shipped map /spawn works only when a switch, sensor, input, or map timer fires it — the very use described here; typed into the console or fired from a macro there, it silently does nothing on press. Cleanup is the author's responsibility, and today the only cleanup verbs the parser exposes are /killall and /kill, both of which currently affect only npcs — so a /spawn of an npc paired with /killall on a switch's off side cleans up cleanly, but a /spawn of any non-npc entity (platform, door, hazard, item, force field, etc.) has no command available to remove it on flip-off and will persist until the next map reload. Friendly names and on-disk tokens are both accepted, the same way /build accepts them.

When the object you spawn or build carries its own quoted text — a sign, a story zone, a menu or text input, and so on — how you write those quotes depends on where the command lives. Typed straight into this console the quotes need nothing special: /spawn sign 5 0 "hi" sign false false works as written. But when the same command is stored inside a switch, sensor, menu input, or text input field, each of those inner quotes must be escaped as a backslash followed by a quote, like \"hi\", so the surrounding field isn't closed early. The builder form escapes them for you when you type the command with ordinary quotes; you only add the backslashes by hand when editing main.sif directly.

/stats, or /st: Brings up the statistics menu. You can also find this in the pause menu of the game.
/stoptime, or /spt: Cancels the current map timer without running its time command — the quiet way to call off a timer, unlike letting it reach zero. Runs silently, or says there's no timer if the map has none.
/subhealth amount, or /sht amount: Subtracts the amount from your character's health; reaching zero costs a life, or ends the game on your last life. Append true to make the amount a percentage of the maximum, or false for an exact value, the default. Runs silently.
/sublevel amount, or /slv amount: Subtracts the amount from your character's level, never below level one, recomputing the experience needed for the next level and trimming experience so the new level sticks; it does not remove points. Runs silently.
/sublife amount, or /slf amount: Subtracts the amount from your character's remaining lives; each life lost refills your health and clears broken bones with the life-lost sound, and dropping to zero ends the game on your last life.
/subpoints amount, or /spn amount: Subtracts the amount from your character's points, stopping at zero. Runs silently.
/substam amount, or /sst amount: Subtracts the amount from your character's stamina, stopping at zero. Append true to make the amount a percentage of the maximum, or false for an exact value, the default. Runs silently.
/subtime time, or /sut time: Subtracts the time from the current map timer's remaining clock; if it reaches zero the timer ends and runs its time command. The time is a number of seconds or clock form like 1:30. Runs silently, or says there's no timer if the map has none.
/subx amount, or /sx amount: Subtracts the amount from your character's x position, clamped to the map's minimum and maximum. Runs silently; on a compiled map it works only when fired by a switch, sensor, input, or map timer, not when typed.
/subxp amount, or /sxp amount: Subtracts the amount from your character's experience, stopping at zero; this does not lower your level. Runs silently.
/suby amount, or /sy amount: Subtracts the amount from your character's y position, clamped to the map's minimum and maximum. Runs silently; on a compiled map it works only when fired by a switch, sensor, input, or map timer, not when typed.
/subz amount, or /sz amount: Subtracts the amount from your character's z position, its height on a 3d map, clamped to the map's minimum and maximum; it has no effect on 2d or topdown maps, which have no z axis. Runs silently; on a compiled map it works only when fired by a switch, sensor, input, or map timer, not when typed.
/suicide, or /sd: Kills your character instantly, depending on how many lives it currently has. On a compiled map this runs only when fired by a switch, sensor, input, or map timer, not when typed.
/take item amount, or /tk item amount: Removes a specified amount of an item from your character's inventory. This is the inverse of /give: where give adds items, take removes them, so you pass the amount as a positive number. Removing more than you currently hold simply clears that item out of your inventory.
/takeall amount, or /ta amount: Removes the specified amount of every item type found across the health, other, and stamina item categories. This is the inverse of /giveall, so the amount is given as a positive number. Removing more than you hold of any item simply clears it out.
/unbuild object, or /ub object: Removes an object you built, the counterpart to build. Typing the object name alone removes the most recently built one of that type; appending coordinates removes the one placed there, as in /unbuild sign 5 0, or /unbuild sign 5 0 3 on a 3d map. A ranged object such as a wall is matched by its minimum corner, and the whole object is removed at once. It works only on decompiled maps, and /undomap can bring a removal back.
/undomap, or /ud: Undoes your most recent map edit, restoring the map to exactly how it was just before that change. This covers adding, editing, and removing a line, and pasting a whole map over the current one — including a paste from /rawdata or from the map menu, so a botched overwrite can be taken back and your full map recovered. You can undo repeatedly to step back through your recent edits, one change at a time. The history is held while you stay on the map and is cleared the moment you load a different one, so undo only reaches back through edits made to the map you're currently on. Speaks a notice if there's nothing left to undo. It works only on decompiled maps.
